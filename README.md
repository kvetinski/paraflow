# ParaFlow

ParaFlow is a twelve-week parallel-systems portfolio project. It will evolve
from a measured scalar implementation into a heterogeneous task-DAG runtime
with Rust orchestration, C++/ISPC/CUDA kernels, and Go experiment tooling.

Day 1 establishes the project boundaries and workload contract. No performance
claims are made before a real scalar execution path exists.

See the complete documentation and quick start added in the Day 1 documentation
milestone.
